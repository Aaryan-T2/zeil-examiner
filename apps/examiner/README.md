# ZEIL Examiner

The full project README — setup, demo walkthrough, architecture, and troubleshooting — lives at the repository root:

**[`../../README.md`](../../README.md)**

```bash
# quick start (from this directory)
npm install
npm run api    # terminal 1 — API on :8787 (reads GEMINI_API_KEY from .env)
npm run dev    # terminal 2 — web app on :5173
```

Demo logins are shown on the login page (`recruiter@examiner.demo` / `candidate@examiner.demo`).
